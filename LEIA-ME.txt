GERADOR DE VÍDEOS DAS PRÉVIAS
=============================
Gera um vídeo vertical (1080x1920, 10 segundos) para cada prévia:
zoom lento no topo, deslize até os serviços, seção sobre, chamada final e fade.
Leva cerca de 40 segundos por vídeo.

INSTALAR (uma vez só)
1. Instale o Node.js (versão LTS) em https://nodejs.org
2. Copie esta pasta para dentro do projeto:
   C:\Users\gipin\OneDrive\Desktop\projeto clinicas\gerador-videos
3. Coloque o arquivo clinicas-import.json dentro desta pasta.
4. Abra o terminal nesta pasta e rode:
      npm install
      npx playwright install chromium

USAR (GERAÇÃO EM LOTE E INDIVIDUAL)
As prévias ficam na pasta ./previews/<SLUG>/index.html.
Os vídeos são salvos na pasta ./videos/<SLUG>.mp4 em 1920x1080 (Desktop Full HD).
Vídeos já existentes são pulados automaticamente. A lista do painel (js/videos-list.js)
é atualizada automaticamente a cada vídeo concluído!

COMANDOS EM LOTE (RECOMENDADOS):
1. Próximos 10 vídeos pendentes:
      npm run videos:lote10
      (ou: node gerar-videos.mjs --limite 10)

2. Modo Rápido (10 vídeos, gravando 2 de cada vez em paralelo):
      npm run videos:rapido
      (ou: node gerar-videos.mjs --limite 10 --paralelo 2)

3. Lote menor de 5 vídeos:
      npm run videos:lote5

4. Todas as 10 clínicas da Camada A (Top 10):
      npm run videos:top10

5. Lote por Ranking específico (ex: rankings 1 ao 20):
      node gerar-videos.mjs --ranking 1-20
      (ou: node gerar-videos.mjs --de 1 --ate 20)

6. Lote por Template (Moderno, Profissional ou Amigavel):
      node gerar-videos.mjs --template Moderno --limite 10

7. Simular antes de gravar (vê a lista sem gastar tempo):
      node gerar-videos.mjs --limite 10 --dry-run

8. Gerar todos os vídeos pendentes do sistema:
      npm run videos

9. Só uma clínica específica:
      node gerar-videos.mjs --only wg-dentista-parque-brasil

10. Regravar vídeos que já existem:
      Acrescente --force ao comando.

DICA: No topo do Painel Web (index.html), clique no botão "🎬 Gravar em Lote"
para escolher e copiar qualquer um desses comandos com 1 clique!

DEIXAR O MOVIMENTO MAIS PRECISO (pedir ao Antigravity)
Nos 3 templates, marque as seções com o atributo data-video:
   data-video="hero"       no topo
   data-video="servicos"   na seção de serviços
   data-video="sobre"      na seção sobre a clínica
   data-video="cta"        na chamada final
Sem as marcações, o script encontra as seções pelos títulos, mas pode errar
em algum layout diferente.

BOTÃO "GERAR VÍDEO" NO PAINEL (próximo passo)
O navegador não consegue rodar este script sozinho. Para ter um botão no card,
o Antigravity precisa criar um pequeno servidor local (Node) que, ao receber
o SLUG, rode:  node gerar-videos.mjs --json clinicas-import.json --only <SLUG>
e depois mostre o vídeo no card.
